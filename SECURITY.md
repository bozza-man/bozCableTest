# Security Policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub: open the **Security** tab of this repository and choose **Report a vulnerability**.

Email security@boz.dev with a description and steps to reproduce. We aim to acknowledge reports within 5 business days and will agree a fix and disclosure timeline with you.

Please do not report security problems in public issues, discussions or pull requests.

## Supported versions

Only the latest version on the default branch receives security fixes.
